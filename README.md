# Calendoro for JavaScript and TypeScript

| Package | What |
|---|---|
| `@calendoro/sdk` | Typed API client |
| `@calendoro/webhooks` | Webhook signature verification (Node and edge) |
| `@calendoro/atoms` | React booking components |
| `@calendoro/mcp` | MCP server for AI agents |
| `calendoro` | Command-line tool |

Each package is built in the Calendoro monorepo, where its full test suite runs, and published from here with npm provenance.
